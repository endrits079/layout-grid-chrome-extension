Download Instructions

To save these icons for your extension:

  1. Right-click on each icon above
  2. Select "Save image as..."
  3. Save as PNG files with these exact names:
    • icon16.png (16×16 icon)
    • icon48.png (48×48 icon)
    • icon128.png (128×128 icon)
  4. Place all three files in your extension folder
